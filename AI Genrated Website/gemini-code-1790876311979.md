# Health Report Understanding & Monitoring System

A modern, responsive full-stack healthcare web application designed to help everyday patients understand complex medical lab reports in plain, friendly language and track physiological parameters over time.

---

## 🌟 Key Features

1. **Clean Healthcare SaaS UI:** Built with custom, modern CSS using clinical design systems, high contrast, readable typography, and complete responsiveness across mobile, tablet, and desktop.
2. **Dynamic End-to-End Workflow:** 
   - Upload any lab report (PDF, PNG, JPG, or TXT).
   - The original file name, actual upload timestamp, and extracted data persist throughout the user journey (Upload → Processing → Analysis → Diet → Precautions → Trends).
   - No hardcoded report names or fixed fake summaries.
3. **Automated Lab Marker Analysis:** Rule-based extraction and evaluation for major clinical biomarkers (Hemoglobin, Fasting Glucose, Cholesterol, Blood Pressure, Vitamin D, TSH, RBC, WBC).
4. **Context-Aware Dietary Guidance:** Generates targeted nutrition rules and meal suggestions based on the actual detected lab values (e.g., iron-rich foods for low hemoglobin, low-glycemic plans for elevated glucose).
5. **Preventive Health & Care Alerts:** Provides actionable daily lifestyle precautions and clear thresholds detailing when to consult a certified physician.
6. **Chronological Health Trend Monitoring:** Tracks multiple reports uploaded within a session on interactive Chart.js line charts.

---

## 💻 Technologies Used

- **Backend:** Python 3.10+, Flask 3.0+
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6)
- **Charts:** Chart.js (via CDN)
- **PDF Extraction:** `pypdf` (falls back gracefully if unstructured)
- **Session Management:** Secure server-side Flask sessions
